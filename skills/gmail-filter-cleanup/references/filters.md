# フィルタの作り方

## フィルタの構成

| 項目 | 内容 |
|---|---|
| 条件 | From / To / 件名 / 含む語句 / 含まない語句 |
| 処理 | ラベルを付ける / 受信トレイをスキップ(アーカイブ)/ 既読にする / 迷惑メールにしない |

## よく使う検索演算子

| 演算子 | 意味 | 例 |
|---|---|---|
| `from:` | 送信元 | `from:@example.com` |
| `to:` | 宛先 | `to:yourname+shop@gmail.com` |
| `subject:` | 件名 | `subject:(ご利用明細)` |
| `OR` / `{ }` | いずれか | `from:{@a.com @b.com}` |
| `-` | 除外 | `from:@shop.example -subject:(発送)` |
| `" "` | 完全一致 | `"お支払い金額"` |
| `has:attachment` | 添付あり | |
| `older_than:` / `newer_than:` | 期間 | `older_than:6m` |
| `label:` | ラベル | `label:お金-カード` |
| `in:inbox` | 受信トレイ内 | |

## 手順

1. 条件を書く
2. **Gmail で検索して、引っかかるメールを確認する**(関係ないメールが混ざっていないか)
3. 処理を決める
4. ユーザーに「条件・処理・該当件数」を見せて承認を取る
5. 作成する。既存のメールにも適用するかを選ぶ

## 受信トレイをスキップしてよいもの・いけないもの

| スキップしてよい | スキップしない(ラベルだけ) |
|---|---|
| 広告・メルマガ | 請求・支払い期限の通知 |
| 発送通知(届けば済むもの) | 本人確認・ログイン通知・セキュリティ警告 |
| 定期的な利用明細のお知らせ | 予約の確定・変更 |
| SNSの通知 | 人からの返信 |

迷ったら、スキップせずラベルだけにする。

## 送信元のアドレスが複数ある場合

同じ会社でも、通知用・広告用・カスタマー対応用でアドレスが違うことが多い。
ドメインでまとめる(`from:@example.co.jp`)か、件名で分ける。

## フィルタの記録

作ったフィルタは `filter-rules.md` に記録する。Gmail の設定画面だけに置くと、
何のために作ったか後でわからなくなる。

```
| 条件 | 処理 | 目的 | 作成日 |
|---|---|---|---|
| from:@card.example | ラベル「お金/カード」 | 利用明細の保管 | 2026-10-31 |
```
