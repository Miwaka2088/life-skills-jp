# 週1回の見直し

フィルタは一度作って終わりではない。新しいサービスを使い始めると、フィルタに引っかからないメールが増える。
週1回、受信トレイに残ったメールから新しいルールを作る。

## 手順

1. 受信トレイの直近1週間のメールを、送信元ごとに集計する
2. 次の基準で候補を挙げる

| 候補の種類 | 基準 |
|---|---|
| 新しいフィルタ | 同じ送信元から週3通以上、かつ毎回読まなくてよい |
| 既存フィルタの修正 | フィルタがあるのに漏れている(アドレスが変わった・別のアドレスから来た) |
| 誤振り分け | ラベルの付いたメールの中に、人からの返信や重要な通知が混ざっていた |
| 配信停止の候補 | 毎週来るが一度も開いていない |

3. 候補を一覧にして、ユーザーに承認を取る
4. 承認されたものだけ実行し、`filter-rules.md` に記録する

## 出力例

```
今週の見直し(11/1〜11/7)

受信トレイに残ったメール: 23通

新しいフィルタの候補
1. from:@news.example(5通・ニュースレター)→ 「ニュースレター」+受信トレイをスキップ
2. from:@ride.example(3通・利用明細)→ 「お金/カード」(スキップしない)

既存フィルタの修正
3. 「買い物/通販」のフィルタに from:@mail.shop.example を追加(アドレスが変わった)

配信停止の候補(ユーザーが自分で停止する)
4. from:@promo.example(週4通・未開封)

どれを実行しますか?
```

## 記録

`filter-rules.md` の末尾に、日付・追加したフィルタ・見送った候補を残す。
見送った候補は翌週また挙げない(ユーザーが判断済みのため)。
