# 物の出入り(買う前の判定と売り先選び)

目的は**「本当に必要なものだけを持つ」**こと。節約そのものではない。
買う前に一度立ち止まり、手放すときは一番手間なく・損なく手放す。

## 守ること

- **買うかどうかはユーザーが決める。** Claude は判定の材料を並べ、「買う/見送る/条件付きで買う」の見立てを示すまで
- **価格・相場・手数料は最新の情報で確認する。** 記憶で答えない。確認できなければ「未確認」と書く
- **出品・購入の操作はしない。** 出品文や価格案は作るが、出品ボタン・購入ボタンはユーザーが押す
- **状態を実際より良く書かない。** 傷・使用感・欠品は正直に書く(トラブル防止)

## 買う前の判定

`references/buy-check.md` を読む。要点:

1. **何の代わりか・何が困っているか**を聞く。「欲しい」だけで、困りごとがないなら見送りの材料になる
2. **手持ちとの重複**を確認する(同じ役割のものを持っていないか)
3. ユーザーのプロフィール(`mono-profile.md`)の**買う基準**に照らす
   例: 家で洗える / 修理できるか使い切れる / 売れる / ロゴが目立たない
4. **使う回数 × 期間**で1回あたりの金額を出す
5. **手放すときに売れるか**(リセール)を見る。売れるものは実質の負担が下がる
6. 見立てを1行で出す: 買う / 見送る / 条件付き(「○○を売ってから」「セールなら」など)

即決しないための一言を添えてよい(「1週間後にまだ欲しければ」など)。ただし押しつけない。

## 手放すときの売り先

`references/sell-channels.md` を読む。物の種類ごとに向いている売り先がある。

| 物の種類 | 向いている売り先の例 | 理由 |
|---|---|---|
| PCパーツ・オーディオ機材など、型番で探される物 | オークション | 型番で探す買い手が競り合うので、相場どおりかそれ以上になりやすい |
| 時計・スニーカー・ブランド小物など、相場が安定している物 | フリマアプリ | 固定価格で早く売れる。相場を見て値付けしやすい |
| デザイナーズブランドの服 | そのブランドに強い専門の古着店・買取店 | 価値をわかる店ほど高く買う。まとめて持ち込める |
| ノーブランドの服・バッグ・雑貨をまとめて | 大手リユース店 | 単価は低いが、一度に片付く |
| 値段がつかない物 | 寄付・回収・自治体の処分 | 売る手間のほうが大きい |

- 手数料・送料を引いた**手取り**で比べる。手数料率は変わるので最新の公式情報で確認する
- **手間も比べる。** 撮影・出品・質問対応・梱包・発送の手間と、店に持ち込む手間
- 早く手放したいのか、高く売りたいのかをユーザーに聞いて選ぶ

## 出品文

`references/listing.md` の形で作る。型番・サイズ・状態・付属品・使用回数を正直に書く。

## 記録

買った物・手放した物を `mono-log.md` に記録する(`assets/mono-log-template.md`)。
- 手放した物は、売り先・金額・手取りを記録する。次に同じ種類の物を売るときの参考になる
- 「買ってよかった物」も記録する。次の買い物の基準になる
