# 買う前の判定

## 聞くこと(順番に、1〜2問ずつ)

1. **何に困っているか / 何の代わりか**
   - 「今のが壊れた」「足りない」なら必要度は高い
   - 「なんとなく欲しい」「セールだから」なら、見送りの材料になる
2. **手持ちで同じ役割の物はあるか**
   - あるなら、それを手放すかどうかもセットで考える(「1つ買ったら1つ手放す」)
3. **どのくらいの頻度で、どのくらいの期間使うか**
4. **置き場所はあるか**(大きい物・家電)
5. **手放すときに売れそうか**

## プロフィールの基準に照らす

`mono-profile.md` に書かれた基準を1つずつ確認する。基準の例:

| 基準 | 確認すること |
|---|---|
| 家で洗える | 洗濯表示。クリーニング必須の素材(カシミア・シルクなど)ではないか |
| 汚れても平気・買い直せる | 定番品で同じ物が手に入るか |
| 修理できるか、使い切れる | 修理の窓口・部品があるか。消耗品なら使い切れる量か |
| 売れる | 中古の相場があるか(フリマ・オークションの売り切れ価格) |
| 目立つロゴ・派手な色を避ける | 写真で確認 |
| 体に合う | サイズ表と手持ちの服の実寸を比べる |

基準に合わない点があれば、それを1行で伝える。

## 1回あたりの金額

```
1回あたり = 価格 ÷ (月の使用回数 × 使う月数)
```

リセールが見込めるなら:

```
実質の負担 = 価格 − 売るときの手取りの見込み
```

相場は**売り切れ価格**で見る(出品中の価格は売れていない価格)。確認できなければ「未確認」とする。

## 見立ての出し方

```
見立て: 条件付きで買う

- 困りごと: 今の物が壊れた(必要度 高)
- 重複: なし
- 基準: 家で洗える ○ / 売れる ○(売り切れ相場 ○円前後、11/3 確認)/ ロゴ △(小さめ)
- 1回あたり: 約○円(週3回 × 2年)
- 条件: 手持ちの○○を先に売るなら、実質○円
```

- 最後は必ずユーザーに判断を任せる
- 「欲しい」気持ちを否定しない。基準に合うなら買ってよいと伝える
