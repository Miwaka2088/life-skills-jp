# 出品文の作り方

## 情報を集める

写真や手元の情報から、次を確認する。わからないものは推測せず聞く。

- 正式な商品名・型番(箱・タグ・本体の刻印から)
- サイズ
- 購入時期・使用回数
- 状態(傷・汚れ・使用感の場所)
- 付属品(箱・タグ・保証書・ケーブル・説明書)の有無
- 動作確認の結果(電子機器)

## タイトル

検索される言葉を前に置く。

```
ブランド名 + 商品名 + 型番 + サイズ/容量 + 状態のひとこと
```

例: `ブランド名 スニーカー 型番 グレー 27cm 箱タグ付き 美品`

「美品」「新品同様」は状態が本当にそうであるときだけ使う。

## 説明文

```
【商品】ブランド名 商品名(型番)
【サイズ】27cm
【購入時期】20XX年○月
【使用回数】十数回
【状態】アッパーはきれいです。ソールに使用による減りがあります(写真○枚目)。
【付属品】箱・タグ
【発送】○○で発送します

ご不明な点はコメントでお聞きください。
```

## 書かないこと

- 状態を実際より良く見せる表現
- 確認していない動作(「動作品」と書くのは確認したときだけ)
- 他の出品者の文章のコピー

## 写真

- 1枚目は全体がわかる写真
- 傷・汚れ・減りがある場所は、必ず別の写真で見せる
- 型番やサイズのタグ、付属品も写す
