# 記入例: 1週間の献立

一人暮らし・平日は弁当を持参・職場に冷蔵庫あり・電子レンジ500W の場合の例。
実際の出力はユーザーのプロフィールと在庫によって変わる。

---

## 依頼

> 今週の献立を組んで。豚こまが550gある。水曜は在宅、土曜は昼に予定あり。

## 在庫(水曜 18:00 時点)

**冷凍庫**
- 茹で汁 … 1袋
- 刻みねぎ … 1本分

**冷蔵庫**
- 豚こま … 550g ※今夜4つに分ける
- 卵 … 9個
- 豆腐 … 1パック
- 納豆 … 2パック
- キムチ … 約380g
- 玉ねぎ … 1/2個
- 惣菜のハンバーグ … 1個(今夜使う)

**常温**
- さば味噌煮缶 … 1個 / レトルトカレー … 2袋
- そうめん … 240g(120g×2食) / ひやむぎ … 240g(120g×2食)
- 米 / オートミール / 調味料一式

---

## 献立

| | 弁当 | 夕食 | 予定 |
|---|---|---|---|
| 水 | — | ひやむぎ120g+ハンバーグ+味噌汁(豆腐半分)+冷奴(豆腐半分) | 在宅 |
| 木 | 豚こま塩だれ+生キャベツ+ゆで卵 | そうめん120g+豚キムチ(豚こま125g+キムチ+玉ねぎ1/2)+ゆで卵 | |
| 金 | 豚こま生姜焼き風+生キャベツ | ひやむぎ120g+さば缶+納豆 | 一番簡単な日 |
| 土 | — | そうめん120g+レトルトカレー+ゆで卵 | 昼に予定 |
| 日 | — | 買い物 → 仕込み30分 → 豚こま125gで豚丼+納豆 | 仕込みの日 |

朝は全日オートミール+ゆで卵1個。

**この例で守っている原則**
- 麺4食分を今週中にすべて消化している(1食120g)
- 豆腐は開けた水曜に、味噌汁と冷奴で半分ずつ使い切る
- 金曜は茹でて缶を開けるだけ
- 豚こま550g = 150g(塩だれ)+150g(生姜焼き風)+125g(豚キムチ)+125g(豚丼)ですべて行き先がある
- 納豆2パックも金・日に割り振っている

---

## 今夜(水曜)やること

- [ ] 豚こま550gを4つに分ける
  - 150g → 塩だれで下味をつけて**冷蔵**(木曜の弁当)
    塩ふたつまみ / 酒小さじ1 / ごま油小さじ1 / にんにくチューブ5mm / こしょう
  - 150g → 生姜焼き風で下味をつけて**冷蔵**(金曜の弁当)
    醤油大さじ1 / みりん小さじ2 / 酒小さじ2 / 砂糖小さじ1/2 / 生しょうが1cm
  - 125g × 2 → プレーンで平たく**冷凍**(木曜の豚キムチ・日曜の豚丼)
- [ ] ゆで卵をまとめて茹でる(朝食4日分+木曜の弁当・夕食、土曜の夕食で計7個。残り2個は翌週へ)
- [ ] 弁当箱を洗う
- [ ] 炊飯タイマーをセット(ご飯0.5合)

※2〜3日以内に使う分は冷凍不要。下味をつけて冷蔵のほうが味が染みる
