# jisui-meal-planner(自炊献立プランナー)

一人暮らしの自炊を「週1回30分の仕込み + 平日は焼くだけ」で続けるための Claude Skill です。

レシピ集ではなく、**食材を余らせない献立の組み方**と**崩れても戻れる運用**をまとめています。
実際に数ヶ月 Claude と一緒に自炊を回してきた中で、続いたこと・続かなかったことを一般化しました。

## 何ができるか

- 1週間の献立表(弁当・夕食)を、在庫と予定から組む
- 買った食材をすべて献立に紐付けた買い物リストを作る
- 日曜の仕込み手順(茹で鶏・下味冷凍・小分け冷凍)を出す
- 毎晩の「今夜やること」チェックリストを出す
- 在庫と献立を `今週の状態.md` に記録し、翌週に引き継ぐ
- 冷蔵庫・レシート・購入履歴の写真から在庫リストを作る

## 考え方

- **買った食材は必ずどこかの食事に紐付ける。** 「適当に食べる」食材ほど余る
- **傷みやすい順に消費する。** 前半に生鮮、後半に冷凍と保険
- **金曜に一番簡単なものを置く。** 疲れた日に外食へ流れるのを防ぐ
- **「開けるだけ・焼くだけ」は続く。「加熱して和えて保存する」は続かない**
- **栄養を削る節約はしない。** 体力が落ちると自炊そのものが崩れる

## 構成

```
jisui-meal-planner/
├── SKILL.md                      # 本体(献立の原則・出力形式)
├── references/
│   ├── sunday-prep.md            # 日曜の仕込み手順・弁当の段取り
│   ├── recipes.md                # 下味冷凍・丼もの・副菜・主食ローテ
│   ├── storage-and-pace.md       # 保存期間・消費ペース・買いすぎ防止
│   └── reading-photos.md         # 写真から在庫を読む手順
├── examples/
│   └── sample-week.md            # 1週間分の出力例
└── assets/
    ├── profile-template.md       # 自分の設定(レンジのW数、調味料、予算など)
    └── weekly-state-template.md  # 毎週更新する在庫・献立・買い物リスト
```

## 使い方

### Claude.ai / Claude アプリ

1. リポジトリの `dist/jisui-meal-planner.skill` をダウンロードする
2. 設定の「スキル」からアップロードする
3. プロジェクトを作り、`profile-template.md` を自分用に埋めたものと、
   `weekly-state-template.md` をコピーした `今週の状態.md` をナレッジに入れる
4. 「今週の献立を組んで」「冷蔵庫に豚こまが300g残ってる」のように話しかける

### Claude Code

```bash
git clone https://github.com/Miwaka2088/life-skills-jp.git
cp -r life-skills-jp/skills/jisui-meal-planner ~/.claude/skills/
```

## カスタマイズ

自分の環境に合わせて変えるのは主に `profile.md` です。Skill 本体は変えなくても動きます。

- 電子レンジのW数(加熱時間は自動で換算されます)
- 職場の冷蔵庫の有無(生野菜をそのまま持っていけるか)
- 手持ちの調味料(ないものは代用表で組みます)
- 食材費の予算、まとめ買いの曜日

## 注意

- 保存期間は一般的な目安です。季節や冷蔵庫の状態で変わります
- 食物アレルギーや医療的な食事制限がある場合は、そちらを優先してください
