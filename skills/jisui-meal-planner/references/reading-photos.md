# 写真から在庫を読む

冷蔵庫・冷凍庫・食品棚・レシート・スーパーのアプリの購入履歴のスクリーンショットを送られたら、
手入力の代わりに写真から在庫リストを作る。

## 手順

1. **写っているものを品目ごとに書き出す。** 保存場所(冷凍庫/冷蔵庫/常温)で分ける
2. **量は見える範囲で書く。** 「豚こま 1パック」「卵 約6個」「キャベツミックス 半袋くらい」
3. **読み取れないものは推測しない。** 「白いタッパー(中身不明)」「奥の袋(品目不明)」として、
   一覧の最後にまとめてユーザーに確認する
4. **期限が写っていれば書き添える。** 写っていなければ空欄のままにする(推測しない)
5. ユーザーの確認を取ってから、今週の状態ファイルの在庫を更新する

## 写真の種類ごとの注意

| 写真 | 読み方 |
|---|---|
| 冷蔵庫・冷凍庫 | 手前の物しか見えないことが多い。「奥にほかに何かありますか」と一言聞く |
| 下味冷凍の袋 | 袋に書いた名前と日付を読む。書いていなければ中身を確認する |
| レシート | 品名が略称になっていることが多い(例: 「ブタコマ」「タマゴ10」)。正式名に直して書く。読めない行は確認する |
| 購入履歴のスクリーンショット | 品名・数量・金額を読む。金額は食費の記録に使える |

## 読み取ったあとにやること

- 在庫と今週の献立を突き合わせ、**どの献立にも紐付いていない食材**を挙げる
- 傷みやすいもの(カット野菜・もやし・開封済み豆腐)が残っていれば、直近の献立に組み込む
- 献立に必要なのに在庫にないものを、次の買い物リストに入れる

## 出力例

```
冷凍庫
- 茹で汁 … 2袋
- 下味冷凍(袋に「塩だれ 11/1」) … 1袋
- 刻みねぎ … 約1本分

冷蔵庫
- 豚こま … 1パック(ラベルが見えず量は不明)
- 卵 … 6個
- 豆腐 … 1パック
- キャベツミックス … 半袋くらい ※2〜3日で使う

確認したいもの
- 下段の白いタッパー(中身不明)
- 豚こまのグラム数
```
