# 保存の目安と消費ペース

## 保存の目安

| 食材 | 保存 | 目安 |
|---|---|---|
| もやし・カット野菜 | 冷蔵 | 2〜3日。1袋ずつ買う |
| 豆腐(開封後) | 冷蔵 | **開けた日に使い切る**。残すと水替えが必要で、それでも2〜3日 |
| 茹で鶏 | 冷蔵 | 3〜4日(茹で汁を少し一緒に入れる) |
| 下味をつけた肉 | 冷蔵 | 2〜3日 |
| ゆで卵(殻付き) | 冷蔵 | 3〜4日 |
| 茹で汁 | 冷凍 | 1ヶ月。夏の冷蔵は3日持たない |
| 下味冷凍 | 冷凍 | 2〜3週間 |
| 小分け冷凍の豚こま | 冷凍 | 2〜3週間 |
| 刻みねぎ | 冷凍 | 1ヶ月 |
| 玉ねぎ | 常温・野菜室 | 1ヶ月(夏は新聞紙に包んで野菜室) |
| 冷凍野菜 | 冷凍 | 1ヶ月 |

## 買う量と消費ペース(一人暮らし・1週間)

| 食材 | 買う量 | 組み込み方 |
|---|---|---|
| カット野菜 | 週1袋 | 生のまま弁当・副菜に。3〜4日で使い切る |
| 冷凍ブロッコリー等 | 1袋を常備 | 味噌汁 / 弁当(自然解凍)/ レンジで添える |
| 豆腐 | 1回1パックを使い切る | 味噌汁+冷奴で同じ日に。または麻婆豆腐で丸ごと |
| 納豆 | 週1パック(3〜4個) | ご飯のある夕食に添える |
| 卵 | 週1パック(10個) | 朝食×7+料理3個(丼・かきたま汁・ゆで卵など) |

卵は「朝食で毎日1個」のように固定枠を先に引き、残りを料理に割り振ると余らない。

## 買いすぎを防ぐルール

- **傷みやすい野菜は2袋買わない。** 安くても使い切れない
- **豆腐・納豆は在庫があれば買わない**
- **紐付け先のない食材はリストに入れない**(献立表のどこにも出てこないなら不要)
- 卵は切らすと朝食が崩れるので、残り3個で補充する
- 平日夜の「ついで買い」を減らし、週1回のまとめ買いで回すのが理想
- 夕方以降の見切り品の肉は、その日に小分け冷凍するなら買ってよい

## 食費の目安の立て方

1回の買い物の概算をリストに書き、週・月の合計を今週の状態に残す。
予算はユーザーのプロフィールに従う。食費を削るために主食や油を減らす提案はしない
(`SKILL.md` の「栄養を削る節約はしない」を参照)。
