# レシピの引き出し

すべて一般的な家庭の調味料で作れるもの。手持ちの調味料はユーザーのプロフィールで確認し、
ないものは代用(末尾の表)で組む。

## 下味冷凍(肉150〜180gあたり)

| 名前 | 配合 | 向いている肉 |
|---|---|---|
| にんにく醤油 | 醤油大さじ1 / 酒小さじ2 / 砂糖小さじ1/2 / にんにくチューブ1.5cm / ごま油小さじ1/2 | 鶏もも・豚こま |
| 塩だれ | 塩ふたつまみ / 酒小さじ1 / ごま油小さじ1 / にんにくチューブ5mm / こしょう多め | 鶏むね・豚こま |
| マヨ醤油 | マヨネーズ小さじ2 / 醤油小さじ2 / 酒小さじ2 / にんにくチューブ1cm | 鶏むね(最もしっとりする) |
| 生姜焼き風 | 醤油大さじ1 / みりん小さじ2 / 酒小さじ2 / 砂糖小さじ1/2 / 生しょうが1cm | 豚こま |
| 味噌漬け | 味噌小さじ2 / みりん小さじ1 / 酒小さじ1 / 砂糖ひとつまみ | 豚こま・鶏もも |
| チキンチャップ | ケチャップ大さじ1.5 / 醤油小さじ1 / 砂糖小さじ1/2 | 鶏もも・鶏むね |
| ピリ辛 | 醤油大さじ1 / 酒小さじ2 / 砂糖小さじ1/2 / 七味多め | 豚こま |
| ステーキシーズニング | 振るだけ。調合不要 | 何でも |

焼き方: 冷蔵庫で解凍 → (鶏むねなら片栗粉をまぶす)→ 油大さじ1で中火、焼き色がついたら返して蓋をし弱火で火を通す。

## 調理法を変えるだけで別料理にする

- **茹でる** … 茹で鶏。汁がスープになるので最も効率が良い
- **焼く** … 下味冷凍の基本
- **揚げ焼き** … 下味冷凍に片栗粉をまぶし、多めの油で。唐揚げ風になり満足度が高い
- **レンジ蒸し** … 火を使いたくない日

## 丼もの(仕込みを増やさずにバリエーションを増やす)

玉ねぎを買い足すだけで作れる(玉ねぎは1ヶ月持つ)。洗い物がフライパンと丼だけなので平日の夜向き。

| 名前 | 材料(1人分) | 時間 |
|---|---|---|
| 豚丼 | 豚こま150g / 玉ねぎ1/4個 / めんつゆ大さじ2 / 砂糖小さじ1 / 水大さじ3強 | 5分 |
| 他人丼 | 豚丼に溶き卵2個を回し入れて蓋をし30秒 | 7分 |
| 親子丼 | 鶏肉150g / 玉ねぎ1/4個 / めんつゆ大さじ2 / 水大さじ5強 / 砂糖小さじ1 / 卵2個 | 8分 |
| 照り焼きチキン丼 | 下味冷凍「にんにく醤油」を焼き、最後にみりん小さじ1で照りを出す | 5分 |
| ねぎ塩チキン丼 | 下味冷凍「塩だれ」を焼き、刻みねぎ+ごま油+塩で和えて乗せる | 5分 |

**卵とじのコツ**: 溶き卵は2回に分ける。半量を回し入れて30秒、残りを入れてすぐ火を止めると
とろりとした半熟になる。一度に入れると固まりすぎる。

## 副菜(「開けるだけ・焼くだけ」で選ぶ)

- 生キャベツ(カット野菜をそのまま。ドレッシングで)
- 冷奴 / 納豆
- ゆで卵
- ツナ+キャベツ和え
- 冷凍ブロッコリー・ほうれん草(凍ったまま味噌汁へ / レンジで温めて添える)
- キムチ

## 主食ローテ

米 / そうめん / ひやむぎ / きしめん / パスタ / 焼きそば / 冷凍うどん

乾麺は日持ちするので常備しておく。夏はそうめん・きしめんが効く。
混ぜご飯(ツナ+めんつゆ、そぼろ)にすると同じ米でも印象が変わる。

## 夕食の標準形

**主菜 + ご飯 + 味噌汁(豆腐+刻みねぎ) + 冷奴 + 納豆**

味噌汁は冷凍した茹で汁を1袋使えば、だしを取る手間もない。

## 4週ローテの目安

| 週 | 主役 | 日曜の仕込み | 弁当への展開 |
|---|---|---|---|
| 1 | 鶏むね | 茹で鶏1枚+下味冷凍3袋 | 茹で鶏を割って乗せる / 朝焼く |
| 2 | 豚こま | 生姜焼き風・味噌漬けで下味冷凍 | 朝焼く。肉巻きにも |
| 3 | ひき肉 | 鶏そぼろを作って冷凍 | ご飯に乗せるだけ。卵そぼろと2色に |
| 4 | 鶏もも | 照り焼き・唐揚げ用に下味冷凍 | 朝焼く。片栗粉で唐揚げ風に |
