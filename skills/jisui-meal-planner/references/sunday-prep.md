# 日曜の仕込み(30分)

買い物 → 仕込み → 冷蔵庫に戻す、までを日曜に一度でやる。平日の夜にやることを「焼く・茹でる・開ける」だけにするのが目的。

## 手順

### 1. 茹で鶏を1枚

鍋に以下を入れて沸かす。

- 水 … 1L
- 塩 … 小さじ1
- 酒 … 大さじ2
- 生しょうが … 1cm(薄切り)
- 長ねぎの青い部分 … あれば

| 部位 | 茹で方 |
|---|---|
| 鶏むね肉 | 沸騰後に入れ、再沸騰したら弱火で2分 → 火を止めて蓋をし、30分放置 |
| ささみ | 沸騰後に入れ、再沸騰したら**すぐ火を止める** → 蓋をして15分放置 |

余熱で火を通すと、パサつかずしっとり仕上がる。
冷蔵で3〜4日。保存容器に茹で汁を少し一緒に入れるとしっとり保てる。

### 2. 茹で汁を小分け冷凍(その日のうちに)

1回分ずつ(味噌汁1杯分)袋に入れて平たく冷凍する。冷凍で1ヶ月。
**冷蔵だと夏場は3日持たない**ので、必ず当日中に冷凍する。
味噌汁のだし、スープ、コンソメの代わりに使える。

### 3. 下味冷凍を2〜3袋

肉150〜180gずつ、ポリ袋に調味料と入れて揉み、空気を抜いて平たくして冷凍する。2〜3週間持つ。
配合は `recipes.md` を参照。

- **片栗粉は下味に入れない。焼く直前にまぶす**(入れて冷凍すると食感が落ち、まぶさないとパサつく)
- 2〜3日以内に使う分は冷凍せず「下味をつけて冷蔵」でよい。味がよく染みる
- 前日の夜に冷蔵庫へ移して解凍し、朝焼いて弁当に詰める

### 4. 豚こまを1食分ずつ小分け冷凍

150g前後ずつラップか袋で**平たく**のばして冷凍する。
平たくしておけば、凍ったままフライパンに入れて火を通せる(解凍忘れの保険になる)。

### 5. 長ねぎを刻んで冷凍

- 小口切り … 味噌汁・薬味用
- 5cmのぶつ切り … 炒め物・丼用

刻んで冷凍すれば1ヶ月持つ。凍ったまま使える。

## 弁当の段取り(平日の朝)

ご飯を朝炊く場合の例。

1. 炊飯タイマーを起床後すぐ炊き上がる時間に設定
2. 炊けたらすぐ弁当箱に**薄く広げて**詰める
3. 身支度の間に冷ます
4. 蓋は出る直前に閉める(温かいまま閉めると水滴がつき傷みやすい)

主菜は前夜に冷蔵庫へ移した下味冷凍を朝焼く。生野菜は詰めるだけ。

## 前夜のチェックリスト(毎晩出す)

- [ ] 翌日の弁当用の下味冷凍を冷蔵庫へ移す

- [ ] ゆで卵が切れていたら2〜3個まとめて茹でる(殻付きで冷蔵3〜4日)
