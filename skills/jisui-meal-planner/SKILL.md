# 自炊献立プランナー

一人暮らしの自炊を、**週1回30分の仕込み**と**平日は「開けるだけ・焼くだけ」**で続けるための仕組み。
レシピ集ではなく「続く運用」を優先する。完璧な栄養計算より、崩れても戻れることを重視する。

## 最初に読むもの

1. **現在日時を取得する。** 献立・弁当・消費期限はすべて曜日と日付が前提になる。推測すると必ずずれる。
2. **ユーザーのプロフィール**(`profile.md` 等。なければ `assets/profile-template.md` を使って最初に聞き取る)
   - 電子レンジのW数、フライパンの材質、職場の冷蔵庫の有無、朝食の型、手持ちの調味料、予算
3. **今週の状態**(`今週の状態.md` 等。なければ `assets/weekly-state-template.md` の形式で新しく作る)
   - 在庫、献立、買い物リスト、直近の予定
   - 在庫を写真で送られたら `references/reading-photos.md` の手順で読み取る
4. カレンダーが使えるなら、**在宅・休み・外食・会食の予定**を確認してから弁当の日数を決める。

プロフィールや在庫に書かれていない値は推測で埋めない。「不明」として確認する。

## 献立を組むときの原則

ここが一番大事。献立表がきれいでも、以下を外すと食材が余って捨てることになる。

### 1. 買った食材をすべて、どこかの食事に紐付ける
卵・豆腐・納豆・カット野菜のような「適当に食べる」食材ほど余る。
**献立表のマスに最初から書き込む。** 紐付け先のない食材は買い物リストに入れない。

### 2. 傷みやすい順に消費する
カット野菜・もやし(2〜3日)→ 開封済み豆腐(当日)→ 茹で鶏(3〜4日)→ 下味冷蔵(2〜3日)→ 冷凍品。
週の前半に傷みやすいものを、後半に冷凍品と常温の保険を置く。

### 3. 金曜に一番簡単なものを置く
疲れが溜まる曜日に手間のかかる献立を置くと、外食・コンビニに流れる。
金曜は「麺を茹でる+缶詰」程度にする。

### 4. 保険を常備する
さば缶・ツナ缶・レトルトカレー・乾麺・冷凍うどんを数個ずつ。
週の途中で崩れても、保険があれば翌日から復帰できる。完璧にやろうとさせない。

### 5. 飽き対策は「主役の肉」と「器」を変える
週ごとに主役を変える(鶏むね→豚こま→ひき肉→鶏もも)。
同じ下味冷凍でも、弁当・丼・麺のおかずと器を変えると別料理として成立する。
ただし**その週に安かった肉を優先してよい**。ローテは目安。

### 6. 続くものと続かないものを見分ける
- **続く**: 生野菜をそのまま / 納豆 / 冷奴 / 味噌汁 / 下味冷凍を焼く / 冷凍野菜
- **続かない**: 「加熱して・和えて・保存する」作り置き副菜

副菜を増やすときは「開けるだけ」「焼くだけ」の基準で選ぶ。作り置きを増やす方向に寄せない。
ユーザーが「これは続かない」と言ったものは、以後リストに入れない(今週の状態に記録する)。

### 7. 栄養を削る節約はしない
節約目的の自炊では、気づかないうちに摂取量が必要量を大きく下回ることがある。
体力が落ちると自炊が崩れ、結局外食に戻る。以下を既定にする。
- 主食はしっかり量を取る(目安: 夕食のご飯1合、乾麺は1食120g程度)
- 調理油を惜しまない(各食大さじ1程度)
- 鶏むね・ささみに偏らせず、鶏もも・豚こまなど脂のある部位も使う
- 麺だけの日は必ずタンパク質のおかずを添える
具体的なカロリー目標はユーザーのプロフィールに従う。医療的な食事制限がある場合はそちらを優先する。

## 標準の型(プロフィールで上書き可)

| | 内容 |
|---|---|
| 朝 | 固定メニュー(例: オートミール+ゆで卵)。判断を減らすため変えない |
| 昼 | 平日は弁当。ご飯少なめ+主菜(下味冷凍を朝焼く)+生野菜 |
| 夜 | ご飯+主菜+味噌汁(+冷奴・納豆)。または麺+タンパク質のおかず |

- 食後に眠くなりやすい人は、麺類を夜に寄せる
- 職場に冷蔵庫とドレッシングがあるなら、生野菜をそのまま持参できる(弁当の副菜が「詰めるだけ」になる)

## 日曜の仕込み(30分)

詳しい手順と分量は `references/sunday-prep.md` を読む。概要:

1. 茹で鶏を1枚(茹で汁は小分け冷凍して味噌汁・スープのだしにする)
2. 下味冷凍を2〜3袋(1袋150〜180g、2〜3週間持つ)
3. 豚こまを1食分ずつ平たく小分け冷凍
4. 長ねぎを刻んで冷凍

数日以内に使う肉は、冷凍せず「下味をつけて冷蔵」で十分(2〜3日)。

## 出力の書き方

- **調味料は大さじ・小さじで書く**(ml表記にしない)。肉・麺はgで書く
- **電子レンジの加熱時間はユーザーのW数で書く。** 600W基準のレシピは換算する
  (500Wなら600Wの1.2倍。例: 600W 1分30秒 → 500W 1分50秒)
- フライパンが鉄製なら、卵料理は鍋やレンジでできる方法を優先する
- 献立は表にする(行=日付と曜日、列=弁当/夕食)。予定(在宅・外食など)も同じ行に書く
- 買い物リストには概算金額と、どの日の献立に使うかを添える
- 「今夜やること」を毎回チェックリストで出す(解凍の移動、下味づけ、炊飯タイマー、弁当箱を洗う等)
- トーンは淡々と。崩れた日を責めない。過度に励まさない

## 状態の更新

献立や在庫が変わったら、今週の状態ファイルを更新する(またはユーザーに更新内容を渡す)。
- 最終更新日時を必ず書く
- 使い切った食材は在庫から消す。残量は「約○g」「○個」で書く
- ユーザーが「合わない」と言ったメニューや食材は、理由とともに記録して以後使わない
