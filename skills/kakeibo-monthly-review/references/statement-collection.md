# 明細の集め方

## 集める日を決める

カードごとに締め日と引落日が違うため、「全部の明細が確定している日」を月1回の収集日にする。

1. プロフィールからカードごとの**締め日**と**引落日**を並べる
2. 最も遅く確定するカード(締め日の後、明細が確定する日)を探す
3. その日以降で、給料日の後の日を収集日にする

例: 締め日が月末・5日・10日・15日のカードを使っている場合、10日締めのカードの明細が確定してから集めると、
前月分がほぼ揃う。こういう組み合わせなら毎月15日前後が収集日になる。

収集日を決めたら、毎月その日にリマインドする(スケジュール機能が使えるなら設定を提案する)。

## 資料の種類と注意

| 資料 | 形式 | 注意 |
|---|---|---|
| クレジットカード明細 | PDF / CSV / アプリのスクショ | **確定分か速報分か**を確認する。速報分は後で金額が変わることがある |
| QRコード決済 | アプリの履歴スクショ | チャージと支払いを混同しない。カードからのチャージはカード明細にも出る |
| 銀行の入出金 | CSV | 期間を前月の給料日〜今月の給料日前日などで揃える。読み方は `bank-csv.md` |
| ローン残高 | 返済予定表 / 会員ページのスクショ | 残高・返済額・利息の内訳が読めるものを選ぶ |
| スーパーの購入履歴 | アプリのスクショ | 食費の内訳を見たいときだけ。毎月必須にしない |

## 足りない資料の頼み方

集まったものを一覧にし、足りないものだけを、どこで取れるかと一緒に頼む。

```
揃っているもの
- カードA(10月分・確定)
- 銀行CSV(10/25〜11/24)

足りないもの
- カードB の10月分の明細(会員サイトの「ご利用明細」からPDF)
- ローン残高(最新の返済後の画面のスクショ)
```

ログインやダウンロードを代わりにはしない。ユーザーに取ってきてもらう。

## スクリーンショットの読み取り

- 画面の端で切れている行は「途中まで」と書き、続きを頼む
- 金額の桁が読めないものは推測しない
- 同じ取引が2枚のスクショに重複して写っていることがある。日付・店名・金額が同じ行は重複を疑って確認する
