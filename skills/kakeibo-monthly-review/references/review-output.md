# レビューの出力形式

毎月同じ形で出す。形が同じだと前月との比較がしやすい。

```

|---|---|
| 収入(手取り) | |
| 支出合計 | |
| 差額 | |

| カテゴリ | 今月 | 予算 | 差 | 前月 |
|---|---|---|---|---|

| 外食・コンビニ | | | | |

| ... | | | | |

|---|---|---|---|
```

## 書き方

- 金額は円単位で、3桁区切りにする
- 予算を超えたカテゴリは「超過 +○円」と事実だけ書く。評価の言葉(「使いすぎ」など)は使わない
- 前月比で大きく変わったものは、理由がわかるなら一言添える(「旅行1回分」など)。わからなければ聞く
- データがない項目は空欄にせず「データなし」と書く
- 要確認が残っている間は、合計に「暫定」と付ける
