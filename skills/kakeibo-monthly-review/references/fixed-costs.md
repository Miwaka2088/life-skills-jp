# 固定費の見直し

固定費は1回の手続きで毎月効くので、変動費を毎日我慢するより効果が大きい。

## 一覧にする

固定費を**月額換算**で一覧にする。年払いは12で割り、週払い・回数制のものは月の平均にする。

| 項目 | 月額 | 契約の更新月 | 解約・変更の条件 |
|---|---|---|---|
| 家賃 | | | |
| 駐車場 | | | |
| 通信(スマホ・回線) | | | |
| サブスク | | | |
| 保険 | | | |
| 習い事 | | | |
| レンタル | | | |
| 分割払い | | | 終了月 |

**更新月と解約条件**がわかっていないものは「未確認」とし、契約書や会員ページで確認してもらう。
見直しは更新月から逆算して予定を立てる。

## 見直しの比べ方

### 解約・頻度を下げる
「なくなったら困るか」をユーザーに聞く。使っている回数と1回あたりの金額を出すと判断しやすい。
例: 月○円で月○回使っている → 1回あたり○円

### 乗り換え
今の契約と候補を、月額・初期費用・違約金・最低利用期間で並べる。
料金は変わるので、候補の金額は**公式サイトの最新情報**で確認してから比べる。

### レンタルの買取
レンタル品を買い取れる場合は、**何ヶ月で元が取れるか**を計算する。

```
回収月数 = 買取価格 ÷ 月額レンタル料
```

- 使い続ける期間より回収月数が短ければ、買取が得
- 回収月数が極端に長いもの(数年以上)は買わない判断材料になる
- 手元の資金に余裕がない時期は、急がない選択肢もあると伝える

### 分割払い
金利0%なら繰上返済しても得はない。終了月を記録して、終わったら月の固定費から外す。

## 記録

決めたことは日付と一緒にレビューのログに残す(「○月の更新で英会話を週1回に変更」など)。
翌月以降のレビューで、実際に固定費が下がったかを確認する。
