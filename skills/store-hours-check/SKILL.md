# 営業時間の裏取り

営業時間は AI が最も間違えやすい情報の一つ。まとめ記事や古い口コミの営業時間をそのまま答えると、
行ってみたら閉まっていた、ということが起きる。**「どこで確認したか」と「確認できなかったこと」を必ず添える。**

## 手順

### 1. 現在日時を取得する
「今日」「今」「この週末」を正しく解釈するため、最初に日付・曜日・時刻を取得する。
祝日・年末年始・お盆・ゴールデンウィークにあたるかも確認する(特別営業になりやすい)。

### 2. 店舗を特定する
チェーン店は店舗ごとに営業時間が違う。**どの店舗か**を特定してから調べる。
同じ名前の店が複数あるときは、住所や最寄り駅で確認する。

### 3. 情報源を優先順に確認する

| 優先 | 情報源 | 理由 |
|---|---|---|
| 1 | 公式サイトの**店舗個別ページ** | 店が自分で更新している。チェーンは店舗検索のページ |
| 2 | 公式SNS(X・Instagramなど)の直近の投稿 | 臨時休業・営業時間の変更が最初に出る |
| 3 | Googleマップの店舗情報 | 店が更新していることが多いが、利用者の編集も入る。特別営業時間の表示も見る |
| 4 | 予約サイト・グルメサイトの店舗ページ | 店が管理していれば信頼できる。最終更新日を見る |
| — | まとめ記事・ブログ・一覧ページ | **確認には使わない。** 店の候補を探すきっかけにだけ使う |

- 1と3が食い違うときは、新しいほうを優先し、**食い違いがあることを伝える**
- 臨時休業は2で見つかることが多い。行く日が近いなら必ず見る

### 4. 書けないことは書かない

- 情報がない項目は「不明・未確認」と書く
- **「載っていない」は「休み」ではない。** 定休日の記載がない店を「定休日なし」「毎日営業」としない
- ラストオーダー・受付終了時間が閉店時間と違うことがある。わかれば両方書く
- 確認できた日付を書く(「11/3 時点の公式サイト」)

### 5. 確実に知りたい場合
予約が必要な店や、遠方から行く場合は、**電話で確認する**ことをすすめる。
電話番号は公式サイトやGoogleマップに載っているものを示す。

## 出力の形

### 1店舗のとき

```
○○ ○○店
- 今日(11/3 火・祝): 11:00〜20:00(公式サイトの店舗ページ、11/3 確認)
- ラストオーダー: 19:30(同上)
- 定休日: 火曜(同上)
- 臨時休業: 公式Instagramに直近のお知らせなし(10/28 の投稿まで確認)
- 注意: Googleマップでは祝日の営業時間が「不明」になっている
```

### 候補を複数挙げるとき
確認済みと未確認を分けて示す。

```
確認済み
| 店 | 今日の営業 | 情報源 |
|---|---|---|
| A | 〜22:00 | 公式サイト(11/3) |
| B | 〜21:00 | Googleマップ(店が更新、10/30) |

未確認(候補だが営業時間を確かめられなかった)
| 店 | わかっていること | 未確認のこと |
|---|---|---|
| C | 通常は〜21:00(グルメサイト、2025年の情報) | 祝日の営業、現在の営業時間 |
```

未確認の店を「おすすめ」の上位に置かない。
